# DeepSeek 对话大纲 v1.0.0

把 DeepSeek 的长对话变成一份可搜索、可离线保存的大纲。这是第一个正式版本，功能与 ChatGPT 版 `chatgpt-conversation-outline` 对齐，数据采集与解析针对 DeepSeek 的接口重写。

## 安装

1. 下载下面的 `deepseek-conversation-outline-1.0.0.zip` 并解压——解压出来是**一个文件夹**，里面直接有 `manifest.json`。
2. Chrome 打开 `chrome://extensions`，右上角启用 **开发者模式**。
3. 点 **加载已解压的扩展程序**，选择解压出来的那个文件夹。
4. 打开任意 DeepSeek 对话页，右下角会出现圆形按钮。

> 从商店安装需要打包发布，目前是"开发者模式 + 加载已解压"的方式，Chrome 会提示这是开发者模式扩展，属正常现象。

## 这个版本有什么

- **提问大纲**：左侧列出本对话的全部提问（过长自动截断），点一条就在右侧显示完整提问与对应回答，长对话不用再一路往上滚。
- **同时搜提问和回答**：命中词在列表和正文里都高亮；只有回答命中时显示"回答中命中 N 处"，并可直接跳到回答。
- **深度思考折叠**：默认收起，可按「搜索含思考」决定是否参与搜索。
- **代码高亮 + 一键复制**：内置 Prism（31 种语言，离线打包），代码块带头部语言名与复制按钮。
- **来源角标**：正文里的 `[reference:N]` 渲染成可点小圆标，悬停看标题、点击开原网页。
- **公式**：`\(…\)`、`$…$`、`$$…$$`、`\[…\]` 都能渲染（KaTeX，输出 MathML）。
- **附件正文**：提问带的附件会列出文件名，点一下按需读取并就地显示（图片直接显示，文本在只读文本框里滚动查看）。
- **复制提问 / 复制回答**：复制回答给的是 Markdown 原文（代码围栏、标题、公式都在），粘到编辑器就是原样。
- **导出单文件 HTML**：整个对话导出成一个自带样式与高亮的 HTML，离线打开后搜索、复制、折叠都还能用。
- **输入框 Enter 换行、Ctrl+Enter 发送**：可在面板里随时开关，不影响 DeepSeek 原生的 Shift+Enter。
- **中英双语界面**：默认跟随浏览器语言，也可在面板右上角手动切换（`auto` / `中文` / `English`）。

## 已知边界

- 代码高亮只覆盖已打包的语言；其他语言按纯文本显示。
- 复制按钮在 https 页面用 `navigator.clipboard`；导出的 HTML 用 `file://` 打开时若没有剪贴板权限，会退化为"选中代码块 + 提示 Ctrl+C"。
- 附件正文只有在网页端**点开过**的才会进导出文件（导出页是离线的，签名地址会被 CORS 拦）；没点开过的保留文件名、大小与原始地址。
- Enter 接管依赖 DeepSeek 当前的输入框结构，大改版后可能需要更新 `ext/src/keymaps.js` 里的选择器。
- 面板打开时需要联网重新取一次历史消息；离线只能看到已截获的部分。

## 验证

本版本在 Chrome 157（Windows）上用真实扩展加载做过回归：77 轮的对话渲染约 1 秒、搜索 33/77 命中、导出 2.3 MB 单文件 HTML（335 个代码块、20815 个高亮片段、0 个外链）、附件 389 KB 文本正常读取并进入导出、中英双语与导出语言一致。细节见仓库 README。

# DeepSeek Conversation Outline v1.0.0

Turn a long DeepSeek conversation into a searchable, offline-saveable outline. This is the first stable release; features match the ChatGPT port `chatgpt-conversation-outline`, while data collection and parsing are rewritten for DeepSeek's API.

## Install

1. Download `deepseek-conversation-outline-1.0.0.zip` below and unzip it — you get **one folder** containing `manifest.json`.
2. Open `chrome://extensions` and enable **Developer mode** (top right).
3. Click **Load unpacked** and pick that unzipped folder.
4. Open any DeepSeek chat — a round button appears at the bottom right.

> Shipping through the Web Store needs a store listing, so for now this is installed as an unpacked, developer-mode extension. Chrome's warning about developer-mode extensions is expected.

## What's in this release

- **Question outline**: every question in the conversation is listed on the left; click one to see the full question and its answer on the right — no more scrolling to the top.
- **Search questions and answers together**: hits are highlighted in both the list and the body; answer-only hits show "N hits in answers" and offer a jump to the answer.
- **Collapsible thinking**: collapsed by default; the "Search thinking" toggle decides whether it takes part in search.
- **Syntax highlighting + one-click copy**: bundled Prism (31 languages, offline), language label and copy button in every code header.
- **Citation chips**: `[reference:N]` becomes a clickable numbered chip with the source title on hover.
- **Math**: `\(…\)`, `$…$`, `$$…$$`, `\[…\]` via KaTeX (MathML output).
- **Attachment text**: files attached to a question are listed by name; click to fetch and show them inline (images render directly, text opens in a read-only box).
- **Copy question / copy answer**: copying an answer gives the Markdown source (code fences, headings and math preserved).
- **Single-file HTML export**: the whole conversation as one self-contained HTML file; search, copy and collapse still work offline.
- **Enter inserts a newline, Ctrl+Enter sends**: toggleable in the panel, and Shift+Enter keeps working as before.
- **Chinese/English UI**: follows the browser language by default; switch manually in the panel header (`auto` / `中文` / `English`).

## Known limits

- Syntax highlighting covers the bundled languages only; anything else renders as plain text.
- Copy buttons use `navigator.clipboard` on https pages; exported HTML opened over `file://` falls back to "select the block and press Ctrl+C" when the clipboard is not permitted.
- Attachment text is only included in an export if it was **opened on the site** first (the exported page is offline and the signed URL is blocked by CORS); otherwise the file name, size and original URL are kept.
- The Enter takeover depends on DeepSeek's current composer markup and may need a selector update in `ext/src/keymaps.js` after a redesign.
- Opening the panel re-fetches the conversation, so it needs network access; offline you only see what was already captured.

## Verification

Verified on Chrome 157 (Windows) with the extension loaded for real: a 77-turn conversation renders in about a second, searching matches 33/77 turns, export produces a 2.3 MB single-file HTML (335 code blocks, 20,815 highlighted tokens, 0 external requests), a 389 KB attachment loads and lands in the export, and the UI/export language follows the selected language. Details are in the repository README.
